### 根治：1062 + 回显失败（casbin 加载管线实锤）

用户实测「授权了还是没回显」并给出日志：`Error 1062: Duplicate entry 'g-user__3-role__read__instance__0------' for key 'idx_cv_pms_casbin_rule'`。**完整根因链**（三方库源码实锤）：

1. gorm-adapter v3.7.4 `loadPolicyLine` 把 DB 行转 policy line 时**从尾部剪掉空字段** → 空 dom 的 g 规则（v2=""）加载后只剩 **2 token**
2. casbin v2.51.0 `persist.LoadPolicyArray` 调 `m.HasPolicyEx(sec, key, rule[1:])`，而 g section 校验 `len(rule) < len(assertion.Tokens)`（2 < 3）即返回 error → **`LoadPolicyArray` 直接 return 跳过该行** → 空 dom 的 g 规则**永远进不了 enforcer 内存**
3. 后果：① 重启后内存查不到 → 回显空；② 重授权时内存 HasPolicy 不命中 → 走适配器 INSERT → 撞 MySQL 唯一索引 → **1062**
4. 附带实锤：casbin `HasPolicy`/`RemovePolicy` 均用 `strings.Join` 键比较，3 token（"u,r,"）与 2 token（"u,r"）永不相等

修复（本轮 3 文件）：
